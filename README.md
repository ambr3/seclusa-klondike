# Seclusa Klondike

Classic solitaire. The game stays on your device.

This game runs in the browser. No sign-up, no adverts, and nothing about how you
play is sent anywhere. Add it to your home screen and it works offline.

- Version 0.2.1
- Play: https://ambr3.github.io/seclusa-klondike/
- Source: https://github.com/ambr3/seclusa-klondike
